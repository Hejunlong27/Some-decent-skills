"Not groundbreaking, not rocket science—just some decent skills that actually get the job done."
（不算惊天动地，也不是什么黑科技——只是一些真正能派上用场的“还行”技能。）

📖 简介 (About)

欢迎来到 Some Decent Skills！

这是一个个人技能库与工具箱，用来存放我在日常开发、折腾工具和解决问题过程中积累下来的各种“还行”的技能。这里没有过度设计的复杂架构，只有经过实战检验的脚本、配置、工作流或 AI 提示词。

✨ 收录内容 (What's Inside)

你可以根据你的实际仓库内容修改以下分类：

🤖 AI & Prompts：好用的系统提示词、Agent 技能定义与工作流配置。

💻 Scripts & CLI：提升终端效率的 Shell / Python 实用小脚本。

⚙️ Dotfiles & Configs：开箱即用的编辑器、终端及开发环境配置。

📝 Cheatsheets：容易忘记但又经常用到的命令速查表与排坑笔记。

📂 目录结构 (Directory Structure)

some-decent-skills/
├── ai-skills/          # AI Agent 技能与提示词模板
├── scripts/            # 自动化与日常效率脚本
├── configs/            # 常用工具配置文件
├── docs/               # 备忘录与使用指南
└── README.md           # 就是你正在看的这个文件


🚀 快速开始 (Getting Started)

克隆仓库到本地：

git clone https://github.com/Hejunlong/some-decent-skills.git
cd some-decent-skills


按需取用：
进入对应的子目录，查看各自的说明文档并运行你需要的脚本或复制配置即可。
